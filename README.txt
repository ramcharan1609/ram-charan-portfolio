RAM CHARAN - MULTI-PAGE PERSONAL PORTFOLIO

Pages:
- index.html (default landing page; same as home.html)
- home.html
- about.html
- education.html
- skills.html
- projects.html
- certifications.html
- contact.html

Shared files:
- style.css (one common stylesheet for every page)
- script.js (one common JavaScript file for every page)
- assets/images/profile.jpg
- assets/images/booknest.png
- assets/images/wanderlust.png

HOW TO RUN:
1. Extract the ZIP file.
2. Keep all HTML pages, style.css, script.js, and assets folder in the same project folder.
3. Open index.html or home.html in your browser.
4. Use the navigation bar to move between pages.

NOTES:
- Bootstrap is loaded through CDN, so an internet connection is required for Bootstrap styling and the mobile navigation.
- The contact form currently performs browser-side validation only. It does not send email until connected to a backend or form service.
- Certification cards are presented as planned/in-progress learning items, not as already-earned certificates.
